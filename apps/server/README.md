# 🦖 DinoTalk Server (Node.js + PostgreSQL + pgvector)

Backend của DinoTalk Kids, là một workspace trong monorepo. Xem hướng dẫn đầy đủ ở [README gốc](../../README.md).

```bash
# Từ thư mục root của repo
npm install
cp .env.example .env   # điền GEMINI_API_KEY, JWT_SECRET
npm run db:up
npm run dev            # http://localhost:4000
```
